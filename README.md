# Cardápio Digital

Site de cardápio online com painel administrativo e acompanhamento de pedido feito para pequena empresas, a página foi realizada durante o nosso TCC. O objetivo era solucionar problemas de empresas de ponte pequeno do setor alimentício trazendo à elas um cardápio multiplataforma intuitivo ao cliente, painel administrativo com criptografia e uma gestão melhorada de produtos.

## Tecnologias:
- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL/Apache
